Task and Understanding for folder watching

🧠 What You’re Building
A Python script that:

Watches a specific folder (e.g., ~/Downloads)

Detects new files as soon as they appear

Prints/logs the filename and path

🔧 Conceptual Components
✅ 1. watchdog.observers.Observer
This is the core engine that monitors file system changes.

You tell it: “Watch this folder”.

✅ 2. FileSystemEventHandler (Custom Class)
You subclass this to define what happens when:

A file is created

A file is modified

A file is deleted, etc.

You’ll override on_created() to act on new files.

✅ 3. Looping the Watcher
The observer needs to keep running. You’ll use while True or try/except to keep the watcher alive until you stop it with Ctrl + C.
